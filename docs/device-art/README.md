# Изображения устройств для «Галереи»

Карточки используют настоящие фотографии и рендеры устройств из официальных каталогов Xiaomi и справки Яндекса. Производители сохраняют права на изображения и товарные знаки. Источник каждого файла указан в `sources.json`; исходные изображения сохранены в `originals/`.

Фотография иллюстрирует **тип устройства**, а не подтверждает его производителя или модель. Публичный пользовательский API Яндекса не сообщает фотографию конкретного устройства. Неизвестные типы получают нейтральную иконку; название, состояние и команды всегда берутся из реального API.

Android-ресурсы `gallery_*.webp` подготовлены с прозрачностью, в размере 280 × 280 px. Все фотографии входят в APK и доступны без дополнительных сетевых запросов. Их суммарный размер — менее 100 КБ.

Сопоставление типов находится в `GalleryDevicePresentation.kt`. Пресеты, параметры устройств или состояние дома эти изображения не изменяют.
