# Действия с циферблата

В версии 1.5.0 источник **«Действие дома»** позволяет назначить отдельное действие каждому слоту циферблата Galaxy Watch / Wear OS.

1. Удерживайте текущий циферблат и откройте его настройку.
2. Перейдите к настройке дополнений/complications и нажмите нужный кружок.
3. Найдите **«Действие дома»** в списке источников Dynorixz Smart Home.
4. Выберите прибор или группу, затем действие: **Переключить**, **Включить**, **Выключить**, **Открыть управление**. Выбор сценария сразу назначает его запуск.
5. Завершите настройку циферблата. Другие кружки можно настроить отдельно.

Интерфейс редактора и поддерживаемые слоты зависят от циферблата; [пример Samsung](https://developer.samsung.com/sdp/blog/en/2025/09/09/build-custom-complications-for-galaxy-watch) показывает системный порядок добавления. Поддержаны SHORT_TEXT, SMALL_IMAGE, MONOCHROMATIC_IMAGE, LONG_TEXT и RANGED_VALUE.

У часов должен быть доступ к интернету и сохранённый вход в Home. Отдельное Home-приложение на телефоне не требуется. После команды показывается короткое подтверждение; ошибка остаётся на экране до нажатия «Готово». Недоступный прибор не переключается.

Для переключения приложение сначала получает фактическое состояние прибора или группы из API Яндекса. Если состояние неизвестно, переключение не выполняется: можно назначить явное включение или выключение. После сценария состояние дома обновляется по возможности. Между действиями состояние на циферблате берётся из кэша и обновляется по системному расписанию с интервалом от пяти минут.

Настройки хранятся по `complicationInstanceId`. Старый общий выбор из настроек приложения служит запасным для ещё не настроенных слотов. Каждому слоту соответствует отдельный immutable PendingIntent; исполняемая команда повторно сверяется с сохранённой настройкой. Пересоздание экрана и повторный запуск во время выполнения не повторяют отправку команды. Холодный сетевой запуск дожидается чтения зашифрованного токена.

Автоматические проверки охватывают независимые настройки слотов и PendingIntent, свежесть состояния перед переключением, явное включение/выключение, отсутствие команды для недоступного прибора, сценарии, группы, восстановление экрана и повторный запуск. Проверяются также форматы предпросмотра маленьких слотов и ожидание токена при запуске процесса.
