# Установка и первый вход

[← Главная](../README.md) · [Скачать релиз 1.8.0](https://github.com/Dynorixz/dynorixz-smart-home-wear-os/releases/tag/v1.8.0) · [Настройка плиток](tiles-1.8.0.md)

## Какой файл скачать

| Файл | Куда устанавливать | Когда нужен |
| --- | --- | --- |
| `Dynorixz-Home-1.8.0-Wear.apk` | Часы с Wear OS 3+ | Основное приложение |
| `Dynorixz-Home-1.8.0-Phone-optional.apk` | Сопряжённый Android-телефон | Только для совместимости со старым callback; для обычного входа 1.8.0 не требуется |
| `Dynorixz-Home-1.8.0-sources.zip` | Компьютер | Полные исходники, ресурсы, документация и Gradle Wrapper |
| `SHA256SUMS.txt` | Компьютер | Контрольные суммы файлов релиза |

Готовый Wear APK уже настроен для Яндекс ID. Создавать собственное OAuth-приложение и вводить Client ID не нужно.

## Если приложение уже установлено

Сначала узнайте версию в **Home → Настройки → О приложении**.

| Установленная сборка | Как обновить |
| --- | --- |
| 1.4.0–1.8.0 с текущим сертификатом | Установить новый Wear APK поверх через `adb install -r`. Вход и настройки сохраняются |
| Публичные 1.2.0 / 1.3.0 | Эти APK подписаны прежним ключом. Нужна однократная переустановка; вход, локальные настройки и назначения ярлыков потребуется повторить |
| Debug APK, форк или другой сертификат | Прямое обновление невозможно. Используйте сборку с той же подписью либо осознанно переустановите приложение |

Если Android сообщает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, это означает несовпадение подписи. Повторная загрузка того же APK это не исправит. Перед переустановкой запомните нужные настройки. Удаление Home с часов не удаляет устройства и сценарии из аккаунта Яндекса.

## Установка через беспроводной ADB

1. На часах откройте **Настройки → О часах → Сведения о ПО** и несколько раз нажмите на версию ПО, чтобы включить режим разработчика. Путь может немного отличаться по модели.
2. Откройте **Параметры разработчика**, включите **Отладку ADB** и **Беспроводную отладку**.
3. Подключите часы и компьютер к одной Wi‑Fi-сети. Откройте на часах **Сопряжение с устройством с помощью кода**.
4. На компьютере с [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) выполните:

```text
adb pair <IP_ЧАСОВ>:<ПОРТ_СОПРЯЖЕНИЯ>
```

Введите код с экрана часов. Затем вернитесь на **основной экран беспроводной отладки**: порт подключения на нём отличается от порта сопряжения.

```text
adb connect <IP_ЧАСОВ>:<ПОРТ_ПОДКЛЮЧЕНИЯ>
adb devices
adb -s <IP_ЧАСОВ>:<ПОРТ_ПОДКЛЮЧЕНИЯ> install -r "Dynorixz-Home-1.8.0-Wear.apk"
```

Команду запускайте из папки с APK или укажите полный путь к нему. `Success` означает успешную установку. Пока идёт подключение и установка, оставьте экран часов включённым. После проверки беспроводную отладку можно выключить.

## Первый вход

1. Откройте Home на часах и нажмите **Войти**.
2. На сопряжённом телефоне откроется браузер с Яндекс ID.
3. Войдите в аккаунт с вашими приборами и разрешите просмотр и управление умным домом.
4. Оставьте Home открытым на часах до завершения входа. После возврата загрузятся устройства, комнаты и сценарии.

На телефоне нужны браузер, Google Play Services и штатное приложение Galaxy Wearable / Wear OS. Устанавливать `Phone-optional.apk` для этого входа не требуется. Если на часах есть браузер, доступен и вариант входа непосредственно на часах.

## Плитки и циферблат

- **Плитки:** с циферблата свайпайте справа налево до конца → **Добавить карточки** / **Добавить плитки** → **Dynorixz Smart Home**. Добавьте «Умный дом», «Свет», «Датчики». Выбор приборов и сценариев меняется через шестерёнку каждой плитки. [Подробная инструкция](tiles-1.8.0.md).
- **Циферблат:** удерживайте циферблат → **Изменить** → выберите поддерживаемый слот → **Действие дома**. Для каждого слота можно назначить своё действие. [Подробная инструкция](complications.md).
- **Главный экран:** Home → **Настройки → Главный экран** → «Список», «Панель» или «Галерея».

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| ADB показывает `offline` или не подключается | Экран часов включён, беспроводная отладка открыта, указан свежий порт с основного экрана. После сна или перезапуска отладки порт может измениться |
| На телефоне не открывается вход | Телефон разблокирован и сопряжён с часами, работают браузер, Google Play Services и Galaxy Wearable / Wear OS |
| После разрешения вход не завершился | Оставьте Home открытым на часах до возврата. Если ожидание отменено или истекло, начните вход заново |
| Нет устройств | Выбран правильный аккаунт Яндекса, в нём есть устройства «Дома с Алисой», разрешён доступ и у часов есть интернет |
| На плитке старые значения | Посмотрите давность снимка, откройте Home и обновите дом. Срок перерисовки плиток определяет Wear OS |
| На плитке «Умный дом» написано «Выберите действия» | Нажмите шестерёнку и выберите до трёх приборов, групп или сценариев |
| «Нет данных» или «Недоступно» | Устройство не передало значение или не доступно в API. Приложение не подменяет отсутствующие показания нулём |
| Нет нужной кнопки управления | Приложение показывает только возможности, объявленные устройством в API Яндекса |

Контрольная сумма основного Wear APK:

```text
13722c830988725030a04a8e2f8257194109a0c9146702d32c275bdb95410f57
```

На Windows:

```powershell
Get-FileHash .\Dynorixz-Home-1.8.0-Wear.apk -Algorithm SHA256
```

Для проверки сертификата используется `apksigner verify --print-certs` из Android SDK Build Tools. Контрольные суммы остальных файлов находятся в `SHA256SUMS.txt` рядом с APK в релизе.
