# Security policy

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости, токены, OAuth-коды, логи аккаунта или данные устройств в публичном Issue.

Используйте приватный канал **Security → Report a vulnerability** в GitHub-репозитории. В сообщении укажите версию приложения, модель устройства, версию Wear OS, шаги воспроизведения и обезличенный диагностический вывод.

## Секреты

- Никогда не добавляйте в Git `local.properties`, keystore, пароли, access/refresh token или OAuth Client Secret.
- Для native OAuth приложению требуется Client ID; Client Secret в APK не используется.
- Перед публикацией логов удаляйте идентификаторы аккаунта, дома, комнат, устройств, локальные IP-адреса и пути пользователя.
