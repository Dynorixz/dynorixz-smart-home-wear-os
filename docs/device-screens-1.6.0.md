# Приборы и показания датчиков — 1.6.0

Каталог приборов открывает поиск и фильтры по кнопкам в компактной шапке. Фильтры состояния, комнаты и типа сохранены, избранные приборы выводятся первыми. Нажатие карточки открывает управление, удерживание меняет избранное, отдельная кнопка питания отправляет команду. Датчики без питания больше не попадают в фильтр «Выключены».

В универсальном экране приборов команды собраны в отдельных панелях: питание, переключатели, диапазоны, режимы и цвет. Значения диапазонов округляются с учётом шага и минимума, объявленных устройством. Кнопки −/+ и шкала отправляют те же реальные CapabilityAction; промежуточные изменения диапазона объединяются существующей очередью DeviceViewModel. Горизонтальный жест шкалы не заменяет вертикальную прокрутку списка. Касание шкалы переводит фокус для управления безелем. Специализированный экран света сохранён; недоступный световой прибор получает универсальный экран с заблокированными командами.

Показания датчиков — информационные карточки, без отключённых кнопок и искусственного уменьшения контраста. Основным выбирается профильное показание, а не батарея или сигнал. Состояния переведены с учётом функции: например, `closed` → «Закрыто», `detected` у движения → «Есть движение», `dry` у протечки → «Сухо». Неизвестное состояние явно обозначается, отсутствующее числовое значение отображается как «Нет данных». Процентная полоса строится только для фактических значений в диапазоне 0–100. Время показания показывается только при наличии его метки от API. Оценки качества воздуха и другие пороги здоровья не выдумываются.

Названия событий и единицы сверены с официальными описаниями Яндекса: [event](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/event-instance), [float](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/float-instance). Для часов при прокрутке используется штатный [scrollAway Wear Material 3](https://developer.android.com/reference/kotlin/androidx/wear/compose/material3/scrollAway.modifier).

В тестовых изображениях используются демонстрационные данные; в приложении источник данных остаётся реальным API Яндекса. Проверяются маленький и большой круглый экран, светлая тема, увеличение шрифта, локализация показаний, неизвестные значения, точность команд и независимое нажатие кнопки питания.
